O que foi feito — histórico dos runs

Como funciona: esta página abre offline e mostra o arquivo oficial progress/tasks.json. Mudar um estado aqui fica só neste navegador (marcado como edição local) até exportar o JSON e importar com python3 scripts/update_progress.py --import arquivo.json. Ao fim de cada run o agente atualiza o JSON com evidências e executa python3 scripts/update_progress.py --end-run --summary "..." --tests "...". Nenhum item vira Concluído sem evidência e sem o critério de aceite inteiro — telas e 3D só com o seu aceite visual; homologações externas continuam bloqueadas até aprovação real. O conteúdo não contém segredos.
